# Makise Kurisu AI Voice (STEINS;GATE) — Qwen3-TTS demo

Type text and hear it in **Makise Kurisu's** voice, in Japanese, Mandarin Chinese or
English. Three voices are available: Kurisu, the Amadeus device voice, and Kurisu on a
phone call. It is an unofficial fan demo of the
[Makise Kurisu Qwen3-TTS model](https://huggingface.co/starrydark/Makise_Kurisu_Qwen3_TTS).
It does not clone voices and never asks for reference audio.

**Also known as:** 牧瀬紅莉栖 · 紅莉栖 · 牧濑红莉栖 · 红莉栖 · 마키세 크리스 · "Christina" ·
Amadeus (アマデウス). From STEINS;GATE (シュタインズ・ゲート / 命运石之门).

- 日本語：牧瀬紅莉栖の声で、日本語・中国語・英語のテキストを読み上げる非公式ファンデモです。
- 中文：用牧濑红莉栖的声音朗读日语、中文、英语文本的非官方粉丝演示（AI 语音合成）。

What v3 adds:
- **Language ids and native Mandarin training data:** much less Japanese accent in
  Mandarin than v2.
- **Two new voices:** Amadeus (the device voice) and phone call.
- **Two experimental tags:** `[sigh]` and `[nv]`.

## How v3 was trained

**The data** comes to 10,970 training rows (13.7 h):
- 8,873 Japanese rows: Kurisu's game studio and anime takes, the Amadeus device voice,
  and phone calls (20 real takes plus 400 takes passed through the show's measured
  phone EQ).
- 1,566 native Mandarin and English replay rows from 55 other speakers (AISHELL-3 and
  LibriTTS-R).
- 531 Kurisu-voiced Mandarin rows generated by the Base model and filtered for native
  pronunciation.

**Conditioning.**
- **Each voice** is a fixed speaker vector stored in the checkpoint.
- **Every row carries Qwen's language id;** a quarter keep the `Auto` layout.
- **`[sigh]` and `[nv]`** are new single tokens.

**Optimisation.**
- **Training:** a full fine-tune with fp32 master weights. AdamW, lr 5e-6 with cosine
  decay, batch 32; the run stopped at 1.25 epochs.
- **Fixes:** the four fixes to the upstream training script used for v2.
- **Hardware:** one H100, about 4 minutes per epoch.
- **Checkpoint choice:** the shipped checkpoint (1.0 epoch) was picked from 6
  candidates by a selection rule written before any result.

**Blind listening test.** One listener rated 16 Mandarin sentences from 1 to 5,
where 5 is native.

| System | Mean rating |
|---|---|
| v3 | 5.0 |
| Native-speaker anchor | 5.0 |
| v2, told the text is Chinese | 3.9 |
| v2, as previously served (Auto) | 3.6 |

v3 was rated above v2 on 9 of the 16 sentences and below it on none.

The full recipe, hyperparameters, logs and code are on the
[model card](https://huggingface.co/starrydark/Makise_Kurisu_Qwen3_TTS#training-details) and in
[`training_code/`](https://huggingface.co/starrydark/Makise_Kurisu_Qwen3_TTS/tree/main/training_code).

## Tips

* **Language: Detect** reads the script of the text (kana -> Japanese, Chinese
  characters only -> Chinese, Latin -> English). Pick a language by hand for mixed text.
* **Voice:** `Kurisu` is the default; `Amadeus` is the device voice from the
  STEINS;GATE 0 game; `Phone call` sounds like she is on the phone.
* **Tags (experimental):** `[sigh]` and `[nv]` (another non-verbal sound) where the
  sound should happen, without spaces, e.g. `[sigh]はぁ……そうね。` They fire on only
  some generations.
* Write pauses as `……` or `――`. Each click samples anew; generate again for a
  different reading.

## Space configuration

| Kind | Name | Value |
|---|---|---|
| Variable (optional) | `MODEL_ID` | `starrydark/Makise_Kurisu_Qwen3_TTS` (default), another hub id, or a local checkpoint directory |
| Secret (private model only) | `HF_TOKEN` | read token for the model repository |
| Variable (optional) | `SPEAKER_NAME` | `kurisu` (default) |

Runs on ZeroGPU: the model is placed on CUDA at module scope and each request
reserves the GPU for up to 60 s. Generation length is capped relative to the input
text so a rare non-stopping sample cannot run away. Input text is normalised the
way the training text was (no spaces next to Japanese characters, none around tags)
and synthesised with the detected or chosen language and the upstream default
sampling. The API endpoint `generate_speech` takes `(text, voice, language)`.
